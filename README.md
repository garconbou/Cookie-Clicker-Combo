# Cookie Clicker — Le guide complet

Site statique en HTML, CSS et JavaScript, sans framework ni dépendance de build.

## Tester en local
Ouvre `index.html` dans ton navigateur.

## Publier sur GitHub Pages
1. Crée un dépôt GitHub (par exemple `cookie-clicker-guide`).
2. Ajoute `index.html`, `style.css` et `script.js` à la racine du dépôt.
3. Dans **Settings → Pages**, choisis **Deploy from a branch**.
4. Sélectionne la branche `main` et le dossier `/ (root)`, puis sauvegarde.
5. GitHub publiera le site à l'adresse affichée dans cette page.

La progression des chapitres lus est sauvegardée dans le navigateur du visiteur via `localStorage`.
Aucun serveur, aucune base de données et aucune installation ne sont nécessaires.
